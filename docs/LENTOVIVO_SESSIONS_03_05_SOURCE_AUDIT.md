### Extraction confidence

- **High confidence:** actual session numbers/titles, chapter timestamps and their text, and explicit page numbers. These come from public video metadata and descriptions.
- **Low confidence / UNVERIFIED:** all notation-level facts, including exact pitches, note values beyond the words “quarter note,” rests, meter, fingering, and hand assignment. These need video frames or readable score pages.
- **Duets:** teacher-student performances are explicitly marked as such in chapters, but the student part cannot be separated from the teacher demonstration without frames/audio.
- **MIDI/audio/theory mode:** chapters do not establish whether a student exercise is intended for MIDI, listening, tapping, or a verbal/theory answer.

### MIDI and timing detail

- MIDI NoteOn is normalized to a pitch attack; NoteOff is captured as a separate input event, but the sequence evaluator ignores it. Consequently, NoteOn/NoteOff transport exists while note duration evaluation does not.
- Rhythm MIDI input turns NoteOn into a beat hit. That supports attack timing but discards pitch for rhythm scoring and does not score key release timing.
- MIDI channel is recorded but is not a reliable physical-hand identifier. Two-hand scoring must not be claimed from channels unless the actual keyboard's routing convention is explicitly established.
- The rhythm generator compiles rests and durations into a timeline. The evaluator expects hits only for non-rest events, so rests are represented but are not independently checked as held/silent intervals.
- Tempo can be selected for practice and the metronome has count-in support. No course BPM was verified, so no target BPM should be authored. A 40–70 BPM progression can be configured when exercise/source timing is verified.
- Progress recording is available through existing services and can record exercise completion; it cannot make incomplete pitch/rhythm scoring complete.
