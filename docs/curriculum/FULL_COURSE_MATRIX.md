# LentoVivo to KeyForge: Full Course Matrix

This is a traceability plan, not a claim that 75 lessons have been source-audited. Session order is canonical. See [source manifest](LENTOVIVO_SOURCE_MANIFEST.md); unavailable sessions remain visible as explicit source gaps.

## Activity classes

- **MIDI Scored:** measurable from configured MIDI note/timing events with current or explicitly planned scoring.
- **Guided Practice:** physical technique, expressive interpretation, posture, or hand assignment that MIDI alone cannot verify.
- **Theory:** notation, terminology, or written/music-symbol knowledge.
- **Ear Training:** listen and recognize/compare musical material.
- **Source-Linked Performance:** practice a named course piece using the learner's authorized book/audio; KeyForge stores a reference and may provide supported, verified targets without distributing copyrighted material.

## Authoring rule

Do not create note- or rhythm-specific session exercises from topic names alone. If a topic is verified but notation is not, retain source URL/chapter/topic metadata as a clearly labeled Guided Practice or Source-Linked Performance activity; any original drill must be labeled adapted and must not be attributed as an exact transcription. MIDI scoring targets, meter, note values, hand labels, tempo and completion thresholds require evidence or must be marked as KeyForge practice design rather than source facts.
