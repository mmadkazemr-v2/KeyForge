## Discovery outcome

Four session-specific metadata records are currently confirmed in the repository/web search evidence (Sessions 03, 04, 05 and 14). Four additional video URLs were supplied as verified leads for Sessions 30, 33, 36 and 37; direct YouTube fetches were throttled and exact-ID web searches returned no results in this pass, so these are retained as **URL lead only**, not metadata-verified lessons. The other 67 of 75 positions have no session-specific URL in the current evidence set. Thus, eight positions have a source URL recorded, four have independently checked title/topic metadata, and 67 remain without a source URL. These counts describe this evidence set, not the creator's actual publication status.

Discovery attempts: opened the four supplied watch URLs (YouTube fetch throttled); searched each video ID and the LentoVivo channel by session number (no results for these exact leads); checked official Book 1/Book 2 publisher support pages (useful book resources, but no creator-session index). No playlist ID or complete channel playlist was found.

The previously shared descriptions say the 75-session course uses Adult Piano Adventures Books 1 and 2. This is a course-level claim; there is no verified one-to-one video/session-to-book-page mapping.
