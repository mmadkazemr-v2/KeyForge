# Keyboard Lab: Alesis V61 MKII arrival checklist

Run these checks on `/keyboard-lab` after connecting the controller by USB. The checks are intentionally left incomplete until physical hardware is available.

- [ ] V61 MKII performance input appears in the MIDI input list.
- [ ] Select the performance input (not an editor/control port).
- [ ] Verify all 61 keys are detected across the keyboard range.
- [ ] Play softly and firmly; confirm velocity values change.
- [ ] Confirm NoteOff clears the pressed-key highlight and releases the sound.
- [ ] Connect a sustain pedal and verify CC64 down/up and held-note release.
- [ ] Test fast repeated notes and a multi-note chord.
- [ ] Unplug USB while a note is held; confirm it releases and status disconnects.
- [ ] Reconnect USB; confirm the same selected device reconnects without switching inputs.
- [ ] Change practice sounds while notes are active; confirm no stuck notes.
- [ ] Play while the metronome runs.
- [ ] Confirm the felt audio latency is playable on the target Windows PC/output.
